## 复现与验收

```bash
python3 -B scripts/generate_demo_cases.py
python3 -B -m unittest discover -s tests -p test_demo_cases.py -v
python3 -B scripts/validate_demo_cases.py load
python3 -B scripts/validate_demo_cases.py verify
```

脚本名称保留以免破坏已有调用；生成出的业务场景名不使用 `demo_*`。导入器限定本次主键前缀，按文件指纹和每 5,000 行检查点恢复；旧数据不计入补充记录的读回数量。

- [manifest.json](../data/case_supplement_v1/manifest.json)：文件行数、SHA-256 和课程说明。
- [import_audit.json](../data/case_supplement_v1/import_audit.json)：本次补充主键范围的导入数量。
- [source_correction.json](../data/case_supplement_v1/source_correction.json)：来源兼容修正范围及读回结果。
- [feature_verification.json](../data/case_supplement_v1/feature_verification.json)：九项既有特征 SQL 的实际查询验收。
- [application_verification.json](../data/case_supplement_v1/application_verification.json)：使用原场景名、原批次，通过现有应用检测 API 和告警详情 API 的验收；使用临时内存 SQLite，不改用户已有规则配置与复核。
